
# குறளகம் | Kuralagam

### Discover the timeless wisdom of Thirukkural through technology.

Kuralagam is a digital platform dedicated to **Thirukkural**, the timeless Tamil literary work by Thiruvalluvar. It brings ancient Tamil wisdom into a modern web experience, making the 1,330 couplets accessible to today's digital generation.

🔗 **Repository:** https://github.com/heymovox/Thirukural

🌐 **API / Deployment:** https://thirukural-server.vercel.app

---

## ✨ Features

- **1,330 Thirukkural Couplets** — Explore the complete collection of Thirukkural.
- **Tamil Literature** — Celebrate and preserve Tamil language and culture.
- **Modern Web Interface** — A React-powered frontend experience.
- **REST API** — An Express.js backend for serving application data.
- **Admin Panel** — Administrative interface for managing platform content.
- **Tamil Calendar** — Access Tamil calendar information.
- **Responsive Experience** — Designed for convenient access across supported devices.

> Feature availability and implementation may vary by the current project version.

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/heymovox/Thirukural.git
cd Thirukural
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Check the project configuration and environment variable requirements before running the application. Create the required `.env` file if needed.

Never commit API keys, passwords, or other secrets to GitHub.

### 4. Run the application

Check the available scripts in `package.json`:

```bash
npm run
```

Run the appropriate development script listed there. The frontend and backend may require separate commands, depending on the project configuration.

## 📜 Cultural Heritage

Thirukkural consists of 1,330 couplets organized into three major divisions:

- **அறத்துப்பால் — Aram:** Virtue
- **பொருட்பால் — Porul:** Wealth and society
- **காமத்துப்பால் — Inbam:** Love

Its teachings continue to inspire generations through timeless insights into ethics, human relationships, leadership, and everyday life.
